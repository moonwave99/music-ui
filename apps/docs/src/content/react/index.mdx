# Music UI - React

A collection of React component wrappers and hooks around the Music UI visualization tools:

- [`<ABCSCore>`](/react/ABCScore) - abc score component;
- [`<ABCSCoreWithPlayer>`](/react/ABCScoreWithPlayer) - abc score component with playback support;
- [`<Piano>`](/react/piano) - piano keyboard component;
- [`<PianoWithPlayer>`](/react/piano-with-player) - piano keyboard component with playback support.
