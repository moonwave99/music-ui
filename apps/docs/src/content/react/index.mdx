# Music UI - React

A collection of React component wrappers and hooks around the Music UI visualization tools:

- [`<ABCSCore>`](/react/abc-score) - abc score component;
- [`<ABCSCoreWithPlayer>`](/react/abc-score-with-player) - abc score component with playback support;
- [`<Fretboard>`](/react/fretboard) - fretboard component;
- [`<Chord>`](/react/chord) - chord diagram component;
- [`<Piano>`](/react/piano) - piano keyboard component;
- [`<PianoWithPlayer>`](/react/piano-with-player) - piano keyboard component with playback support.
