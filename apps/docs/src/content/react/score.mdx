# Score

The `<Score>` component renders ABC notation as music score on screen.

## Installation

<Tabs items={['pnpm', 'npm', 'yarn']}>
  <Tabs.Tab>
  ```
  pnpm install @music-ui/react
  ```
  </Tabs.Tab>
  <Tabs.Tab>
  ```
  npm install @music-ui/react
  ```
  </Tabs.Tab>
  <Tabs.Tab>
  ```
  yarn add @music-ui/react
  ```
  </Tabs.Tab>
</Tabs>
