# PianoPlayer

The `<PianoPlayer>` component adds playback functionality to the `<Piano>` component.

## Installation

<Tabs items={["pnpm", "npm", "yarn"]}>
  <Tabs.Tab>``` pnpm install @music-ui/react ```</Tabs.Tab>
  <Tabs.Tab>``` npm install @music-ui/react ```</Tabs.Tab>
  <Tabs.Tab>``` yarn add @music-ui/react ```</Tabs.Tab>
</Tabs>

## Basic usage

The following code renders a piano with the passed notes and the playback buttons:

<Callout type="warning">
Since the player backend is shared, you have to wrap your app into a `<PlayerProvider>`.
</Callout>

```tsx
import { PianoPlayer, PlayerProvider } from "@music-ui/react";
import "@music-ui/piano/styles.css";

function App() {
  return (
    <main>
      <PlayerProvider>
        <PianoPlayer notes="C4 E4 G4 B4" noteLabels="1 3 5 7" />
      </PlayerProvider>
    </main>
  );
}
```
