# Fretboard

The `<Fretboard>` component is a React wrapper around the [`Fretboard` class](/javascript/fretboard/fretboard).

## Installation

<Installation packageName="@music-ui/react" />

## Usage

The following code renders an empty fretboard with the default `Fretboard` options:

```tsx
import { Fretboard } from "@music-ui/react";

function App() {
  return (
    <main>
      <h1>My App</h1>
      {/* rest of your app */}
      <Fretboard />
    </main>
  );
}
```

Output:

<Fretboard />

<Callout type="info">
  Check [the complete `Fretboard` component
  reference](/api/functions/_music-ui_react.Fretboard.html) for more details.
</Callout>

## Component props

The component accepts the following props:

| Name        | Type     | Default Value | Description                     |
| ----------- | -------- | ------------- | ------------------------------- |
| `id`        | `string` |               | The fretboard unique identifier |
| `className` | `string` |               | The component class name        |
