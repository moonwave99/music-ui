# ABCScore

The `<ABCScore>` component renders ABC notation as music score on screen.

## Installation

<Installation packageName="@music-ui/react" />

## Basic usage

The following code renders a score with the passed notes and the playback buttons:

<Callout type="warning">
Wrap your app in a `<PlayerProvider>` if you want to use playback features.
</Callout>

```tsx
import { Score, PlayerProvider } from "@music-ui/react";

function App() {
  return (
    <PlayerProvider>
      <main>
        <h1>My App</h1>
        {/* rest of your app */}
        <ABCScore>
          M:4/4
          L:1/8
          CDEF GABc|
        </ABCScore>
      </main>
    </PlayerProvider>
  );
}
```
