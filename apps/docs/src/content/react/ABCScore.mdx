# ABCScore

The `<ABCScore>` component renders ABC notation on screen.

## Installation

<Installation packageName="@music-ui/react" />

## Usage

The following code renders a score with the passed notes:

```tsx
import { ABCScore } from "@music-ui/react";

function App() {
  return (
    <main>
      <h1>My App</h1>
      {/* rest of your app */}
      <ABCScore>
        M:4/4
        CDEF GABc|
      </ABCScore>
    </main>
  );
}
```

<ABCScore showTempo={false}>
CDEF GABc|
</ABCScore>

Without time signature:

<ABCScore showTimeSignature={false} showTempo={false}>
CDEF GABc|
</ABCScore>

With free tempo:

<ABCScore showTimeSignature={false} showTempo={false}>
M: 1/1
L: 1/1
C D E F G A B c || c d e f g a b c' |
</ABCScore>
