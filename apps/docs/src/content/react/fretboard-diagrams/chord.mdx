# Chord

The `<Chord>` React component renders guitar chords diagrams.

## Installation

<Installation packageName="@music-ui/react" />

## Usage

The following code renders an open C chord:

```tsx
import { Chord } from "@music-ui/react";

function App() {
  return (
    <main>
      <h1>My App</h1>
      {/* rest of your app */}
      <Chord input="x32010" chordName="C major" />
    </main>
  );
}
```

Output:

<Chord input="x32010" chordName="C major" />

## Component props

In addition to the [`Fretboard` component props](/react/fretboard-diagrams/fretboard#component-props), the component accepts the following props:

| Name                 | Type                  | Default Value | Description                     |
| -------------------- | --------------------- | ------------- | ------------------------------- |
| `input`              | `string`              |               | The chord input (e.g. `x32010`) |
| `chordName`          | `string`              |               | The chord name (e.g. "C major") |
| `barres`             | `Barre` \| `Barres[]` |               | One or more chord barres        |
| `includeOpenStrings` | `boolean`             | `false`       | Shows the open string positions |
| `showName`           | `boolean`             | `false`       | Shows the chord name            |

## Props showcase

A showcase of the component props:

```tsx
import { Chord } from "@music-ui/react";

function App() {
  return (
    <>
      <Chord input="x32010" chordName="C major" showName />
      <Chord
        input="x32010"
        chordName="C major"
        showNoteNames
        includeOpenStrings
      />
      <Chord
        input="x355421"
        barres={{ fret: 3, stringFrom: 5 }}
        chordName="C minor"
        crop
        showName={false}
      />
    </>
  );
}
```

### `showNoteNames` and `includeOpenStrings`

<Chord input="x32010" chordName="C minor" showNoteNames includeOpenStrings />

<Callout type="info">
  In order to display the right note name (e.g. `Eb` vs `D#`), the `chordName`
  property **must include the chord quality** (e.g. `major` or `minor`), see:
</Callout>

```tsx
import { Chord } from "@music-ui/react";

function App() {
  return (
    <>
      <Chord input="133111" showNoteNames includeOpenStrings />
      <Chord
        input="133111"
        chordName="F minor"
        showNoteNames
        includeOpenStrings
      />
    </>
  );
}
```

No `chordName`: displays `G#` on the third string, first fret:

<Chord input="133111" showNoteNames includeOpenStrings />

Right `chordName`: displays `Ab` on the third string, first fret:

<Chord input="133111" chordName="F minor" showNoteNames includeOpenStrings />
