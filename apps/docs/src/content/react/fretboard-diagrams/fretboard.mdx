# Fretboard

The `<Fretboard>` React component is a wrapper around the [`Fretboard` class](/javascript/fretboard-diagrams/fretboard).

## Installation

<Installation packageName="@music-ui/react" />

## Usage

The following code renders an empty fretboard with the default `Fretboard` options:

```tsx
import { Fretboard } from "@music-ui/react";

function App() {
  return (
    <main>
      <h1>My App</h1>
      {/* rest of your app */}
      <Fretboard />
    </main>
  );
}
```

Output:

<Fretboard />

<Callout type="info">
  Check [the complete `Fretboard` component
  reference](/api/functions/_music-ui_react.Fretboard.html) for more details.
</Callout>

## Component props

In addition to the [`Fretboard` class constructor options](/javascript/fretboard-diagrams/fretboard#constructor), the component accepts the following props:

| Name            | Type      | Default Value | Description                     |
| --------------- | --------- | ------------- | ------------------------------- |
| `id`            | `string`  |               | The fretboard unique identifier |
| `className`     | `string`  |               | The component class name        |
| `showNoteNames` | `boolean` | `false`       | Display the note names          |

## Props showcase

A showcase of the component props:

```tsx
import { Fretboard } from "@music-ui/react";

const cMajorArpeggio = [
  { string: 6, fret: 0, note: "E" },
  { string: 6, fret: 3, note: "G" },
  { string: 5, fret: 3, note: "C" },
  { string: 4, fret: 2, note: "E" },
  { string: 3, fret: 0, note: "G" },
  { string: 2, fret: 1, note: "C" },
  { string: 1, fret: 0, note: "E" },
  { string: 1, fret: 3, note: "G" },
];

function App() {
  return (
    <>
      <Fretboard positions={cMajorArpeggio} fretCount={3} width={300} />
      <Fretboard
        positions={cMajorArpeggio}
        width={600}
        fretCount={5}
        showNoteNames
      />
      <Fretboard
        positions={cMajorArpeggio}
        width={600}
        fretCount={5}
        style={{
          text: ({ note }) => note!,
          fill: ({ note }) => (note === "C" ? "orange" : "white"),
        }}
      />
    </>
  );
}
```
