# Render ABC notation

[ABC notation](https://abcnotation.com/) is a form of music notation that is easily parsable and editable by both people and machines.  
This library uses [abc.js](https://github.com/paulrosen/abcjs) to render ABC notation as music scores on screen.

## Basic usage

You are free to organize your markup as desired, yet the following structure is convenient:

- a wrapper element holding both the abc notation and the visual element (e.g. `.score`);
- the container of the abc notation (e.g. `.score .content`);
- the element where the score is rendered (e.g. `.score .staff`).

```html
<div class="score">
  <div class="content">
M:4/4
L:1/4
C D E F G A B c|
  </div>
  <div class="staff"></div>
</div>
```

<Callout type="info">Don't forget to hide the notation element via CSS: `.score .content { display: none; }`</Callout>

You can then render the content:

```ts
import { initAbc } from '@music-ui/abc';

const element = document.querySelector('.score');

initAbc({
  content: element.querySelector('.content').textContent,
  staffElement: element.querySelector('.staff'),
});
```

Output:

<Score hidePlayer>
M:4/4
L:1/4
C D E F G A B c|
</Score>
