## Usage

The `@music-ui/piano` package exports an `initPianoWithPlayer` function that expects the same markup of [`initPiano`](/javascript/piano-keyboard/basic-usage#usage):

```html
<div data-piano data-notes="C4 E4 G4 B4"></div>
```

In addition to the `initPiano` parameters, it needs a `Player` instance in order to playback the notes:

```ts
import { initPianoWithPlayer } from "@music-ui/piano";
import { playerFactory } from "@music-ui/player";
import "@music-ui/piano/styles.css";

const player = playerFactory();

initPianoWithPlayer({ player });
```
