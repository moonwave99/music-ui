# Basic Usage

Need to display a piano diagram with some highlighted notes?

## Installation

<Installation packageName="@music-ui/piano" />

## Usage

The `@music-ui/piano` package exports an `initPiano` function.

By default it selects all `[data-piano]` element inside the document:

```html
<div data-piano></div>
```

Setup code:

```ts
import { initPiano } from "@music-ui/piano";
import "@music-ui/piano/styles.css";

initPiano();
```

Output:

<Piano />

You can pass a custom selector or collection of elements.

```html
<div class="my-piano"></div>
<div class="my-piano"></div>
```

Setup code:

```ts
import { initPiano } from "@music-ui/piano";
import "@music-ui/piano/styles.css";

// via selector string
initPiano({ selection: ".my-piano" });

// via actual DOM selection
initPiano({ selection: document.querySelectorAll(".my-piano") });
```

Output:

<Piano />

<Piano />

## Note highlight

You can highlight specific notes via the `data-notes` attribute:

```html
<div data-piano data-notes="C4 E4 G4 B4"></div>
```

Setup code:

```ts
import { initPiano } from "@music-ui/piano";
import "@music-ui/piano/styles.css";

initPiano();
```

Output:

<Piano notes="C4 E4 G4 B4" octaves={3} />

<Callout type="warning">
  To avoid position ambiguity, always append the octave after the note (i.e. use
  [scientific pitch
  notation](https://en.wikipedia.org/wiki/Scientific_pitch_notation)).
</Callout>

### Multiple voices

You can highlight different group of notes in different colors, e.g. when you need to separate left and right hand content.

Separate the note groups via a comma, like:

```html
<div data-piano data-notes="C3 C4, E4 G4 C5"></div>
```

Setup code:

```ts
import { initPiano } from "@music-ui/piano";
import "@music-ui/piano/styles.css";

initPiano();
```

Output:

<Piano notes="C3 C4, E4 G4 C5" octaves={3} />

## Render options

Configuration can be passed via data attributes:

```html
<div
  data-piano
  data-start-octave="2"
  data-octaves="4"
  data-with-final-c="false"
  data-show-octaves
></div>
```

Setup code:

```ts
import { initPiano } from "@music-ui/piano";
import "@music-ui/piano/styles.css";

initPiano();
```

Output:

<Piano octaves={3} withFinalC={false} startOctave={2} showOctaves />

The following data attributes are supported:

| Attribute           | Type      | Description                                 |
| ------------------- | --------- | ------------------------------------------- |
| `data-octaves`      | `number`  | The amount of rendered octaves              |
| `data-start-octave` | `number`  | The first octave being rendered             |
| `data-with-final-c` | `boolean` | Renders a final C key after the last octave |
| `data-show-octaves` | `boolean` | Displays the octave number on every C note  |
| `data-notes`        | `string`  | The notes to be highlighted                 |
| `data-note-labels`  | `string`  | The note labels                             |

<Callout type="info">
  Check [the complete `initPiano` API
  reference](/api/functions/_music-ui_piano.initPiano.html) for more details.
</Callout>

## Appearance customization

All the sizes and colors are configurable via CSS variables.

The defaults are found [in the imported CSS file](https://github.com/moonwave99/music-ui/blob/main/packages/piano/src/styles/index.css).

You can override them in your style files.
