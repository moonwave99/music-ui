The `@music-ui/piano` package provide various ways to render keyboard diagrams:

- [the `initPiano` function](/javascript/piano-keyboard/basic-usage): the quickest way;
- [the `initPianoWithPlayer` function](/javascript/piano-keyboard/usage-with-player): with playback support;
- [the `Piano` class](/javascript/piano-keyboard/piano): full control, more configuration needed.
