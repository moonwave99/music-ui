# Basic Usage

If you just need to render some [abc music notation](https://abcnotation.com/) on screen, this is the simplest approach.

## Installation

<Installation packageName="@music-ui/abc" />

## Usage

The `@music-ui/abc` package exports an `initABCScore` function.

By default it selects all the `[data-abc-score]` elements, and expects them to have the following children:

- an element containing **the abc notation**, with the `.content` class;
- an element where **the music notation will be rendered**, with the `.staff` class.

For more granularity you can use the [`ABCScore` class](/javascript/music-notation/ABCScore).

```html
<div data-abc-score>
  <div class="content">
    CDEF GABc|
  </div>
  <div class="staff"></div>
</div>
```

<Callout type="info">
The `.content` element is hidden by default inside `@music-ui/abc/styles.css`.
</Callout>

Setup code:

```ts
import { initABCScore } from "@music-ui/abc";
import "@music-ui/abc/styles.css";

initABCScore();
```

Output:

<ABCScore>
CDEF GABc|
</ABCScore>

You can pass a custom selector or collection of elements. In this example we'll select all `.score` elements:

```html
<div class="score">
  <div class="content">
    CDEF GABc|
  </div>
  <div class="staff"></div>
</div>
<div class="score">
  <div class="content">
    K:G
    GABc defg|
  </div>
  <div class="staff"></div>
</div>
```

Setup code:

```ts
import { initABCScore } from "@music-ui/abc";
import "@music-ui/abc/styles.css";

// via selector string
initABCScore({ selection: ".score"});

// via actual DOM selection
initABCScore({ selection: document.querySelectorAll('.score') });
```

Output:

<ABCScore>
CDEF GABc|
</ABCScore>

<ABCScore>
K:G
GABc defg|
</ABCScore>

<Callout type="info">
  Check [the complete `initABCScore` API
  reference](/api/functions/_music-ui_abc.initABCScore.html) for more details.
</Callout>

### Dataset options

The `initABCScore` function reads the parameters passed in the **data attributes** of the _wrapper element_:

```html
<div
  data-abc-score
  data-show-tempo="false"
  data-show-time-signature="false"
>
  <div class="content">
    CDEF GABc|
  </div>
  <div class="staff"></div>
</div>
```

Setup code:

```ts
import { initABCScore } from "@music-ui/abc";
import "@music-ui/abc/styles.css";

initABCScore();
```

Output:

<ABCScore showPlayer={false} showTempo={false} showTimeSignature={false}>
CDEF GABc|
</ABCScore>

The following data attributes are supported:

| Attribute                  | Type      | Description                         |
| -------------------------- | --------- | ----------------------------------- |
| `data-show-tempo`          | `boolean` | Shows or hides the tempo indication |
| `data-show-time-signature` | `boolean` | Shows or hides the time signature   |

### Passing `abc.js` options

You can pass an `abcOptions` parameter, that will be forwarded to the `abc.js` renderer.

You can see the available options [on the library documentation](https://docs.abcjs.net/visual/render-abc-options).

```html
<div data-abc-score data-show-tempo="false">
  <div class="content">
    CDEF GABc|
  </div>
  <div class="staff"></div>
</div>
```

Setup code:

```ts
import { initABCScore } from "@music-ui/abc";
import "@music-ui/abc/styles.css";

initABCScore({
  abcOptions: foregroundColor: "orange"
});
```

Output:

<ABCScore
  showTempo={false}
  showPlayer={false}
  abcOptions={{ foregroundColor: "orange" }}>
  CDEF GABc|
</ABCScore>

<Callout type="warning">
  The passed options will be shared across all selected elements. <br /> If you
  need more control, you can call `initABCScore` multiple times with different
  selections and parameters or create your own widget with the various
  `music-ui` classes.
</Callout>
