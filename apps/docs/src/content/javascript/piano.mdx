# Piano

The `Piano` component renders a piano keyboard inside a DOM element.

## Installation

<Installation packageName="@music-ui/piano" />

## Basic usage

By default, the `initPiano` function selects a `#piano` element inside the document:

```html
<div id="piano"></div>
```

Setup code:

```ts
import { initPiano } from "@music-ui/piano";
import "@music-ui/piano/styles.css";

initPiano();
```

Output:

<Piano />

You can select a different element:

```html
<div id="my-element"></div>
```

Setup code:

```ts
import { initPiano } from "@music-ui/piano";
import "@music-ui/piano/styles.css";

// you can pass a selector string
initPiano("#my-element");

// or you can pass a previously selected HTMLElement
const element = document.getElementById("my-element");
initPiano(element);
```

### Rendering more pianos at once

The `initPiano` functions initializes all the elements that match the selector / that are passed:

```html
<div data-piano></div>
<div data-piano></div>
```

Setup code:

```ts
import { initPiano } from "@music-ui/piano";
import "@music-ui/piano/styles.css";

// with selector
initPiano("[data-piano]");

// with selection
const elements = document.querySelectorAll("[data-piano]");
initPiano(elements);
```

Output:

<Piano />

<Piano />

Rendering multiple similar empty keyboards is not particularly exciting. Let's see how to customize them and to highlight some notes inside them!

### Dataset options

The `initPiano` function reads the parameters passed in the `data-*` attributes:

```html
<div id="piano" data-octaves="4" data-with-final-c="false"></div>
```

Setup code:

```ts
import { initPiano } from "@music-ui/piano";
import "@music-ui/piano/styles.css";

initPiano();
```

Output:

<Piano octaves={3} withFinalC={false} />

The following data attributes are supported:

| Attribute           | Type      | Maps to `Piano` option | Description                                 |
| ------------------- | --------- | ---------------------- | ------------------------------------------- |
| `data-octaves`      | `number`  | `octaves`              | The amount of rendered octaves              |
| `data-start-octave` | `number`  | `startOctave`          | The first octave being rendered             |
| `data-with-final-c` | `boolean` | `withFinalC`           | Renders a final C key after the last octave |

<Callout type="info">
  Check [the complete `initPiano` API
  reference](/api/functions/_music-ui_piano.initPiano.html) for more details.
</Callout>

## Appearance customization

All the sizes and colors are configurable via CSS variables. These are the defaults:

```css
--piano-height: 4rem;
--piano-white-key-width: 1.2rem;
--piano-black-key-width: 0.8rem;
--piano-black-key-height: 60%;
--piano-white-key-played-indicator-size: calc(
  var(--piano-white-key-width) / 3 * 2
);
--piano-black-key-played-indicator-size: calc(var(--piano-black-key-width));
--piano-played-indicator-background-color: rgba(255, 255, 255, 0.9);
--piano-key-label-font-size: 0.7rem;
--piano-border-color: rgba(0, 0, 0, 0.4);
--piano-white-key-color: white;
--piano-black-key-color: rgb(35, 35, 35);
--piano-white-key-group-1-highlight-color: dodgerblue;
--piano-black-key-group-1-highlight-color: dodgerblue;
--piano-white-key-group-2-highlight-color: lightcoral;
--piano-black-key-group-2-highlight-color: lightcoral;
--piano-white-key-group-3-highlight-color: gold;
--piano-black-key-group-3-highlight-color: gold;
--piano-white-key-group-4-highlight-color: lightgreen;
--piano-black-key-group-4-highlight-color: lightgreen;
--piano-white-key-group-5-highlight-color: lightcoral;
--piano-black-key-group-5-highlight-color: lightcoral;
```

You can override them in your style files.

## The `Piano` class

If you need more control over the component lifecycle, you can use the underlying `Piano` class.

<Callout type="info">
  Check [the complete `Piano` API
  reference](/api/classes/_music-ui_piano.Piano.html) for more details.
</Callout>

### Constructor

The `Piano` constructor accepts the following parameters:

| Property      | Type                      | Default  | Description                                   |
| ------------- | ------------------------- | -------- | --------------------------------------------- |
| `element`     | `string` \| `HTMLElement` | `#piano` | The container element or a valid CSS selector |
| `octaves`     | `number`                  | 2        | The amount of rendered octaves                |
| `startOctave` | `number`                  | 3        | The first octave being rendered               |
| `withFinalC`  | `boolean`                 | true     | Renders a final C key after the last octave   |

### Note highlight

You can highlight specific notes with `Piano.setNotes`:

```ts {3}
const piano = new Piano({ element: "#my-element" });
piano.render();
piano.setNotes("C4 E4 G4");
```

And a C major chord is highlighted:

<Piano notes="C4 E4 G4" />

<Callout type="warning">
  Always append the desired octave after the note in order to avoid ambiguity,
  e.g. `C4` for middle C. This is especially relevant for any chord that crosses
  the octave line, e.g. `A3 C#4 E4 G4`.
</Callout>

### Highlight different groups

If you want to split hands or outline specific voices, separate the groups via a comma:

```ts {6}
const piano = new Piano({
  element: "#my-element",
  octaves: 4,
});
piano.render();
piano.setNotes("C3 C4, E4 G4 C5");
```

Et voilà:

<Piano notes="C3 C4, E4 G4 C5" octaves={3} />

### Display note labels

You can pass the labels to be displayed in the highlighted keys as a second parameter to `Piano.setNotes`:

```ts {3}
const piano = new Piano({ element: "#my-element" });
piano.render();
piano.setNotes("F3 A3 C4 E4", "1 3 5 7");
```

<Piano notes="F3 A3 C4 E4" noteLabels="1 3 5 7" />

<Callout type="warning">
  The `noteLabels` and `notes` length should match.
</Callout>

### Clearing note highlight

Use `piano.clearNotes`:

```ts {5}
const piano = new Piano({ element: "#my-element" });
piano.render();
piano.setNotes("C4 E4 G4");
// later on
piano.clearNotes();
```

### Setting additional note state

Use `piano.setPlayedNotes` for playback scenarios when state changes over time but you still want to highlight the same set of notes:

```ts {7}
const piano = new Piano({
  element: "#my-element",
  octaves: 3,
});
piano.render();
piano.setNotes("C4 E4 G4");
piano.setPlayedNotes("C4 G4");
```

See:

<Piano notes="C4 E4 G4" playedNotes="C4 G4" />

### Clearing played notes

Use `piano.clearPlayedNotes`:

```ts {6}
const piano = new Piano({ element: "#my-element" });
piano.render();
piano.setNotes("C4 E4 G4");
piano.setPlayedNotes("C4 G4");
// later on
piano.clearPlayedNotes();
```
